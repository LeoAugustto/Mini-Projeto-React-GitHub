# Mini Projeto React + GitHub

Projeto desenvolvido para a atividade prática de React com GitHub.

## Objetivo

Criar uma aplicação React utilizando:

- Componentes
- `useState`
- `useEffect`
- Git e GitHub

## Funcionalidades

- Adicionar tarefa
- Remover tarefa
- Marcar tarefa como concluída
- Contador de tarefas totais, pendentes e concluídas
- Componentes separados para botão, tarefa e lista

## Estrutura principal

```text
src/
├── components/
│   ├── button/
│   ├── task/
│   └── task-list/
├── App.js
├── App.css
├── index.js
└── index.css
```

## Como executar

Instale as dependências:

```bash
npm install
```

Inicie o projeto:

```bash
npm start
```

Depois acesse no navegador:

```text
http://localhost:3000
```

- React

- HTML
